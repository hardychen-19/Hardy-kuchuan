# 首次使用与排错

这是给 Agent 的操作资料，不要整篇转给用户。

## 运行时与安装

找到当前宿主可用的 Node.js 22.13+ 后用其绝对路径运行；不要只检查 PATH 就判断未安装。没有可用版本时，Agent 可通过当前环境已配置的包管理器或 Node 官方安装程序协助安装，遵守宿主权限要求，说明新增软件和范围。不要使用陌生镜像、关闭执行策略、强制管理员权限或默默替换现有项目的全局运行时。需要用户完成系统安装窗口时，只指出该动作；完成后再次检查版本再继续。

用户仅提供下载包时，定位含 SKILL.md 的目录。Codex 可运行包内 `install.cjs`，默认安装到 CODEX_HOME（未设置时为用户主目录/.codex）下的 skills/hardy-kuchuan；安装器遇已有目录会停止。检查已有技能版本后再更新技能文件，保留用户自定义和本地设备配置。Agent 能直接读取当前技能时，可以先按本技能引导，不必等下一次会话；宿主暂不发现新技能时才提示新开会话。

只下载文件无法自动唤醒一个 Agent；宿主必须加载 Skill 并具备本地命令和文件访问能力。当前验证目标是 Codex。其他 Agent 可读相同说明，但其安装发现机制、权限与工具需单独验证。

## 手机入口

包内 `assets/mini-program.json` 描述体验阶段、AppID、入口页面、二维码期限与更新仓库。setup 检查期限并在过期时不返回二维码路径；准确性依赖电脑时间。微信实际报过期或无权限时，以微信反馈为准。

- 无权限：当前仍是体验版，需联系库传管理员添加本人的微信 ID 为体验成员。Agent 无管理员授权时不能代加。无需微信密码、AppSecret 或验证码。
- 过期：向公开仓库检查新版入口资源；仍过期则由管理员更新。不要要求用户注册开发者账号、购买云服务或自己部署服务器。
- 白屏：退出后重进，确认扫的是当前体验码；管理员需核查入口 `pages/index/index` 和体验版本。不反复生成电脑绑定码试图修复手机白屏。
- 入口正常后再启动绑定请求。12 位电脑绑定码与小程序二维码是两回事；确认的是当前设备与当前手机微信账号。

## 目录和凭据

setup 读取真实系统 Documents 位置（Windows 使用系统 MyDocuments），不要替换为作者路径。默认子目录为 `00-Inbox/库传`；旧绑定保持原路径。Windows 默认路径可能被 OneDrive/企业策略重定向：选择本机 NTFS 固定磁盘，网络盘或不支持独占硬链接的目录不能使用。若用户不希望其他云同步该目录，请改到其指定的本机目录。

已绑定时，setup 不修复或迁移目录。目录丢失、权限拒绝或配置损坏先解释具体问题，确认原盘可用再恢复；不要删除配置后“重新开始”。

Mac 系统钥匙串弹窗由用户授权。Windows DPAPI 仅适用于原 Windows 登录用户和电脑；从另一台电脑复制凭据不可用。同一系统用户下的其他软件仍可能读取凭据，不能承诺应用间隔离。

## 故障路由

| 症状 | Agent 操作 |
| --- | --- |
| 尚未绑定 | 回到首次引导；不要把正常新用户状态当系统故障 |
| 网络超时 / 服务不可达 | 检查联网，用已配置公开入口诊断；不更换为 localhost 或重绑来绕过；一次重试仍失败则报告具体阻塞 |
| 已有配置，但授权失效 | 说明原设备授权失效；仅用户明确同意重绑时用 `bind --replace yes`，不能自动换账号 |
| 凭据读取失败 | 检查原系统用户、系统钥匙串权限或 Windows PowerShell；不打印凭据，不降级明文存储 |
| 同步进程锁 | 运行 `doctor`；仅当程序确认进程已不存在且返回 stale 时用 `doctor --repair-lock yes`，运行中锁不删除 |
| partial / 确认失败 | 保留已写文件，用同一配置重试 sync；不清空收件箱或重置游标 |
| 手机保存但本机 0 条 | status 核对已绑定设备、真实收件目录；引导核对手机登录账号与保存提示；重复内容可能已去重；不要取别人的令牌排查 |
| 想解绑 | 用户请求后执行 logout；说明这移除本机凭据，云端设备可在手机撤销 |

`status` 查询云端设备与当前本地目录；`doctor` 检查服务、设备授权和同步锁。这些命令输出不包含设备令牌。

## 用户主动要求测试时

引导在手机保存一条带独有标记的链接及一条普通文字；sync 后核对两类文件与文字待确认状态。再同步应无重复新增。测试第二微信号时，双方各保存独有内容并用各自绑定电脑同步，核对不出现对方内容；未真正做完不能宣称隔离已验收。不要让每位普通用户都做完整开发测试。
